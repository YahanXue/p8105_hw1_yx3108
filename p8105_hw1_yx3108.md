The mean can be calculated for the numeric and logical variables. For
the logical variable, R treats `TRUE` as 1 and `FALSE` as 0, so its mean
represents the proportion of values that are `TRUE`. The character and
factor variables do not have meaningful arithmetic means, and `mean()`
returns `NA` with a warning.

Next, I mannually convert the logical, character, and factor variables
to numeric variables.

``` r
as.numeric(pull(problem2_df, logical_vector))
as.numeric(pull(problem2_df, character_vector))
```

    ## Warning: NAs introduced by coercion

``` r
as.numeric(pull(problem2_df, factor_vector))
```

Logical values convert `FALSE` to 0 and `TRUE` to 1. So the mean of a
logical variable can be calculated.

The character variable contains non-numeric strings, so it turns to
numeric produces `NA` values.

The factor variable is converted to integer codes corresponding to its
factor levels. These integer codes represent the internal coding of the
factor levels, which are not meaningful numerical values.
